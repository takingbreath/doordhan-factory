# Voice Card — <Character Name>

One card per character, at `docs/voices/<name>/voice-card.md`, next to that character's `reference/` folder.
The format file says who the character is. This card says how they sound. Don't repeat what the format file already says.

Rules for filling it in:
- Describe behaviour, never adjectives. "Sarcastic" tells a model nothing. "When a caller asks something obvious, he repeats the question back slowly" tells it everything.
- Describe moves, not lines. No sample dialogue here — real speech lives in `reference/`.
- Measured numbers come from `reference/rhythm.md`. Don't guess them.
